title: "Persistence & Sleep"
description: "Persist VM filesystem and Core state with SQLite."
---

Core durable state uses `agentos_core_*` tables and filesystem storage uses
`agentos_fs_*`. Each owner has an independent schema version and migration
transaction.

This durable metadata does not make the default VM filesystem persistent. The
default root is an ephemeral in-memory overlay and is discarded when the VM is
replaced. Configure a `durable` root or mount only for paths that need to
survive VM replacement.

Configured durable filesystems survive VM replacement. Running processes,
terminals, open streams, and live subscriptions do not.
